About Nepali Utilities

A small, free collection of tools and daily widgets built for everyday use in Nepal.

Nepali Utilities started as a simple idea: put the small things people look up constantly — the current time, today's weather, a quick date check, converting a number into words — in one fast page. No sign-up, no app to install, nothing to configure.

What's here

The home page shows live world clocks alongside Nepal time, current weather for major Nepali cities, today's date with both English and Nepali details, and a daily quote. Below that is a growing set of standalone tools, starting with a number to Nepali words converter for writing amounts on cheques, forms and receipts.

How it's built

The site is a set of static pages with no account system and no server-side database. Preferences like your time format and chosen city are kept only in your own browser. Weather data comes from WeatherAPI.com. See the Privacy Policy for details.

Support this site

Nepali Utilities is free to use and supported by advertising. If you find a tool useful, sharing it with someone who'd find it handy helps keep it running.

Contact

Found a bug, or want a tool added? Reach out through the repository this site is built from, or via the contact details you've set up for your domain.
